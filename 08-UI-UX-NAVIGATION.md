# UI/UX & Navigation

## Design Direction

Nuansa:
- calm civic,
- modern residential,
- bersih,
- profesional,
- hangat,
- tidak seperti SaaS template generik.

## Anti AI-Slop

Hindari:
- gradient berlebihan,
- kartu KPI berwarna-warni,
- icon dekoratif random,
- sidebar hitam standar,
- chart hanya untuk memenuhi ruang,
- emoji dashboard berlebihan,
- glassmorphism.

## Typography

Gunakan:
- Geist,
- Inter,
- Manrope.

Angka finansial:

```css
font-variant-numeric: tabular-nums;
```
